# Plan 04-01: Risk Scoring, Decoupled Confidence, Officer Final Decision & Ground-Truth Evaluation

## Objective
Implement unsupervised machine learning anomaly detection (Engine #8: Isolation Forest), decouple Risk Score (threat severity) from Confidence Score (evidential certainty), replace automatic clearance with Scheme Officer Final Decision gating, and benchmark the pipeline using synthetic ground-truth (Precision, Recall, F1).

## Tasks
1. Implement `isolation_forest_engine.py` (ENG-08) evaluating 6-dimensional feature vectors with explainable driver extraction.
2. Implement `risk_scorer.py` (RISK-01) computing cumulative weighted severity score (0-100) and advisory triage recommendations.
3. Implement `confidence_engine.py` (RISK-02, RISK-05) decoupling evidential certainty (0-100%) from risk severity.
4. Implement `rationale_generator.py` (RISK-03) synthesizing executive plain-English fraud explanations for scheme officers.
5. Implement `admin_routes.py` with `POST /api/admin/applications/{id}/decision` (ADM-05, ADM-06) enforcing officer final decision and audit logging.
6. Implement `model_evaluation.py` (EVAL-01) benchmarking the pipeline on synthetic ground truth via `GET /api/admin/evaluation/metrics`.
7. Author comprehensive test suite `test_ml_and_decisions.py` and verify all 64 backend tests pass.
