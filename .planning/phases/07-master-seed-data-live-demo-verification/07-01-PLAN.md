# Plan 07-01: Master Seed Data & End-to-End Live Demo Verification

## Objective
Provision comprehensive realistic Indian agriculture seed fixtures for PM-KISAN fraud detection demo, and execute end-to-end verification across both citizen submission and administrative review workflows.

## Tasks
1. **SEED-01: Default Auth Credentials**:
   - Provision Scheme Officer Admin account (`admin@pmkisan.gov.in` / `Admin@123`).
   - Provision Primary Farmer account (`farmer@test.com` / `Farmer@123`).
2. **SEED-02: Master Registries Provisioning**:
   - 25+ Land Record Master records (`land_records_master`).
   - 25+ Bank Validation Master records (`bank_validation_master`).
   - 20+ Exclusion Master records (`exclusion_master`).
   - 20+ Village Profile Master records (`village_profile_master`).
   - 20+ Event Calendar Master records (`event_calendar_master`).
3. **SEED-03: 20 Diverse Applications Across Risk Tiers**:
   - 10 Low Risk applications (clean claims, verified OTP/eKYC, matching land & bank).
   - 5 Medium Risk applications (disputed land, partial name mismatch, village density spike, unverified OTP).
   - 5 High/Critical Risk applications (taxpayer exclusion, deceased identity, non-agricultural land, duplicate parcel claim, mule account).
   - Pipeline execution populating AnomalyReports, AnomalyFlags, and plain-English rationales.
4. **SEED-04: End-to-End Verification Test Suite**:
   - Author `test_e2e_verification.py` verifying registration, login, submission, salt-hashed Aadhaar privacy, redaction, detection engines, admin adjudication, and audit logs.
