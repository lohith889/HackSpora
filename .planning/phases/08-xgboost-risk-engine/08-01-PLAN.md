# Plan 08-01: Supervised XGBoost Risk Engine, Feature Extractor & TreeSHAP Explainability

## Objective
Implement a high-performance, two-stage hybrid risk scoring sub-system using XGBoost (`xgboost>=2.0.0`) and TreeSHAP (`shap>=0.44.0`). Vectorize application claims and multi-engine signals into a normalized 24-dimensional feature vector, enforce 100% strict Boolean statutory exclusion overrides ($Risk = 100$), compute non-linear fraud probabilities, extract the top 3 predictive SHAP drivers, persist ML scores to the database, and verify through automated testing.

## Context & Architecture Contracts
- Consumes [`08-AI-SPEC.md`](file:///D:/lohith/hackspora/.planning/phases/08-xgboost-risk-engine/08-AI-SPEC.md).
- **Statutory Invariant**: If an applicant triggers any `EXCLUSION_*` or `LAND_PARCEL_NOT_FOUND` flag, the final hybrid score must be forced to `100` (`is_statutory_override = True`), preventing probabilistic ML dilution.
- **Explainability Contract**: TreeSHAP must calculate feature attributions using tree-path perturbation without external background datasets for sub-5ms latency.
- **Privacy Invariant**: Raw 12-digit Aadhaar numbers must never enter the feature vector; only salted hash presence/degree.

### 3. XGBoost Model Training, Calibration & Inference Engine (`XGB-03`)
- Create [`backend/app/services/xgboost_risk_engine.py`](file:///D:/lohith/hackspora/backend/app/services/xgboost_risk_engine.py):
  - Implement `generate_reference_training_data()` synthesizing 120 balanced training samples (clean farmers, statutory exclusions, non-linear syndicates, and borderline cases).
  - Implement `get_trained_xgboost_model()` with cache check for `backend/models/xgboost_risk_model.json`. If missing, trains deterministic `XGBClassifier` (`max_depth=4`, `learning_rate=0.08`, `random_state=42`) and saves artifact.
  - Implement `evaluate_xgboost_risk(details, flags, db) -> MLRiskEvaluationResult`:
    - Checks statutory exclusion hit: if True $\to$ returns score=100, `is_statutory_override=True`.
    - Else runs `booster.predict(dmatrix)` $\to$ `ml_risk_score = round(prob * 100)`.
    - Computes TreeSHAP attributions and returns top 3 drivers.
