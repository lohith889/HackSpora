# Plan 08-02: Admin UI Dual-Risk Meters, SHAP Waterfall Bar Chart & ML Divergence Badging

## Objective
Enhance the Scheme Officer Review Console to present the two-stage hybrid ML scoring results. Display side-by-side Dual Risk Meters (Heuristic Rule Score vs. XGBoost ML Score), an interactive horizontal SHAP Feature Attribution bar chart detailing the top 3 mathematical drivers of suspicion, statutory override banners, and ML divergence badges across application tables.

## Context & Architecture Contracts
- Follows GIGW 3.0 government styling (clean Inter typography, accessible contrast, rounded cards, official badge styling).
- Consumes the ML payload fields exposed by Plan 08-01: `ml_risk_score`, `is_statutory_override`, `divergence_score`, and `ml_shap_drivers`.
- **Zero Citizen Exposure**: These ML scores and SHAP charts are strictly restricted to Scheme Officers (`/admin/*`) and must never be rendered on the citizen tracking portal (`DashboardPage.jsx`, `ApplicationDetailPage.jsx`).

## Tasks
