# Plan 03-01: Identity, Land & Bank Anomaly Engines (Wave 1)

## Objective
Implement the first three anomaly detection engines covering Identity (e-KYC, OTP, duplicate Aadhaar, bulk mobile), Land (master record existence, Aadhaar match, fuzzy name, agricultural flag, area discrepancy), and Bank (IFSC validity, account status, fuzzy name, mule account detection). Each engine returns a structured list of `AnomalyFlagResult` dataclass objects with a code, severity, score, rationale, and evidence dict.

## Context
- All engines receive `PMKisanApplicationDetails` and a `db: Session`.
- Engines must never raise unhandled exceptions — they log flags and return empty lists if nothing suspicious.
- Fuzzy name matching uses `thefuzz.fuzz.token_sort_ratio`; threshold = 80 for Low, 65 for Medium, 50 for High anomaly.
- Severity levels map to score contributions: `Low=10`, `Medium=25`, `High=40`, `Critical=55`.
- Flag codes follow the naming pattern `IDENTITY_*`, `LAND_*`, `BANK_*`.

## Shared Result Dataclass
Create `backend/app/services/engine_types.py` with:
```python
from dataclasses import dataclass, field
from typing import Any, Dict, Optional

@dataclass
class AnomalyFlagResult:
    anomaly_code: str
    severity: str        # "Low" | "Medium" | "High" | "Critical"
    score: int           # 10 | 25 | 40 | 55
    rationale: str
    evidence_json: Optional[Dict[str, Any]] = field(default_factory=dict)
```

<task id="3">
<title>Implement Land Record Anomaly Engine</title>
<action>

2. **LAND_OWNER_AADHAAR_MISMATCH** (High, 40): if `master.owner_aadhaar_ref` is not None and `master.owner_aadhaar_ref != details.aadhaar_ref`. Evidence: `{"master_aadhaar_ref": "...", "applicant_aadhaar_ref": "..."}`.
3. **LAND_OWNER_NAME_MISMATCH** (Medium, 25 / High, 40): apply `thefuzz.fuzz.token_sort_ratio(details.farmer_name.lower(), master.owner_name.lower())`. If score < 65 → High (40); if score < 80 → Medium (25). Evidence: `{"declared_name": "...", "master_name": "...", "fuzzy_score": N}`.

6. **LAND_AREA_DISCREPANCY** (Medium, 25 / High, 40): compute `pct_diff = abs(details.declared_land_area_ha - master.land_area_ha) / master.land_area_ha * 100`. If > 50% → High (40); if > 20% → Medium (25). Evidence: `{"declared_ha": ..., "master_ha": ..., "pct_diff": ...}`.
