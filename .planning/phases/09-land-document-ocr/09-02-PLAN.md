# Plan 09-02: Admin Land Deed OCR Dossier UI, Sample Fixtures & Verification

## Objective
Provide administrative transparency into uploaded land deeds by building the Scheme Officer **Land Deed OCR Authenticity Dossier** in `AdminApplicationDetailPage.jsx`. Seed realistic synthetic Bhulekh / RoR land deed PDFs (matching and mismatching) for demo verification, enable document preview/download, and display side-by-side claim vs. extracted ID comparisons with clear fraud alert badges.

## Context & Architecture Contracts
- Consumes the OCR fields exposed by Plan 09-01: `ocr_extracted_doc_id`, `ocr_status`, `ocr_match_status`, `ocr_confidence_score`, and `ocr_extracted_data`.
- Adheres to GIGW 3.0 government aesthetic (clean borders, high-contrast badges, Inter font, official Indian government color motifs).
- **Citizen Isolation**: The OCR inspection card is restricted exclusively to the Scheme Officer console (`/admin/*`) and must never appear in citizen-facing views.

## Tasks

### 1. Realistic Land Deed Document Generation in Seeder (`OCR-05`)
- In [`backend/seed.py`](file:///D:/lohith/hackspora/backend/seed.py):
  - Use `reportlab` to generate authentic-looking synthetic Uttar Pradesh Bhulekh RoR (Record of Rights) / Khatauni extract PDFs in `backend/uploads/`:
    - `seed_land_doc_valid_45.pdf`: Contains header "UTTAR PRADESH BHULEKH - KHATAUNI", Document No `DOC-UP-2024-884920`, Parcel ID `UP-LKO-MAL-V001-K102-P45`, Plot 45, Khata 102, Owner "Ramesh Kumar", Area "1.85 Ha".
    - `seed_land_doc_mismatch_99.pdf`: Contains Document No `DOC-UP-2024-999001`, Parcel ID `UP-BAR-FAT-V009-K999-P99`, Plot 99, Khata 999, Owner "Fake Syndicate Member", Area "4.50 Ha".
    - `seed_land_doc_unreadable.pdf`: Blank or corrupted PDF for unreadable test cases.
  - Wire these generated PDFs into the sample seed applications:
    - Clean applicant has matching PDF $\to$ `ocr_match_status = "MATCHED"`.
    - Fraudulent applicant has mismatched PDF $\to$ triggers `LAND_DOC_ID_MISMATCH` with `ocr_match_status = "MISMATCH"`.

### 2. Admin Land Deed OCR Verification Dossier Card (`OCR-05`)
- Update [`frontend/src/pages/admin/AdminApplicationDetailPage.jsx`](file:///D:/lohith/hackspora/frontend/src/pages/admin/AdminApplicationDetailPage.jsx):
  - In the "Land & Parcel Information" section, add a dedicated **"Land Deed OCR Verification Dossier"** card:
    - Header: Document icon, filename, and direct "View / Download Uploaded Deed" link.
    - Badges:
      - `MATCHED` $\to$ Emerald badge: *"Automated OCR Verified — Parcel ID & Plot Match"*
      - `MISMATCH` $\to$ Red/Rose alert badge: *"Fraud Alert — Document ID Mismatch Detected"*
      - `UNREADABLE` $\to$ Amber badge: *"Notice — Document Text Illegible / Manual Review Required"*
    - **Side-by-Side Comparison Grid**:
      - Column 1: Attribute (Document / Parcel ID, Plot / Khasra, Khatauni No, Land Area, Titleholder Name).
      - Column 2: Declared in Application.
      - Column 3: Extracted from Uploaded Document via OCR.
      - Column 4: Comparison Status (Green check or Red discrepancy alert).
    - **OCR Evidential Confidence Gauge**: Displays extraction confidence score (e.g. 96%).
    - **Raw OCR Text Inspector**: Collapsible monospaced box displaying the raw extracted text snippet for complete officer auditing and transparency.
